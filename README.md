## What I'm building

**[Sentinel-EC](https://github.com/Sohanuu66/Sentinel-EC)** — Fraud detection backend on the IEEE-CIS dataset (590K transactions, 28:1 class imbalance); CatBoost with time-based CV hit ROC-AUC 0.902 and PR-AUC 0.437. FastAPI inference backend with real-time and batch scoring, containerised with Docker, tracked in MLflow, artifacts on AWS S3. *In progress.*

`Python` `CatBoost` `FastAPI` `MLflow` `MongoDB Atlas` `Docker` `AWS S3`
